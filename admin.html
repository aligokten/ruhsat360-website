Yönetim Paneli

Fiyat/paketleri ve Sıkça Sorulan Sorular'ı buradan güncelleyin. Kaydettiğinizde site birkaç dakika içinde otomatik güncellenir.

1. Bağlantı

Kaydedebilmek için GitHub erişim anahtarınızı (token) girin. Yalnızca bu tarayıcıda saklanır, siteye kaydedilmez.

Gelişmiş ayarlar
GitHub anahtarı (token) nasıl oluşturulur?
  1. github.com/settings/tokens → Fine-grained tokens → Generate new token.
  2. İsim verin, Expiration seçin (ör. 90 gün).
  3. Repository access → Only select repositories → ruhsat360-website seçin.
  4. Permissions → Repository permissions → Contents için Read and write seçin.
  5. Oluşturup kopyalayın, yukarıdaki kutuya yapıştırın. (Anahtar bir daha gösterilmez.)

2. Fiyatlandırma

Planları düzenleyin, ekleyin veya çıkarın.

3. Sıkça Sorulan Sorular

Soru ekleyin, düzenleyin veya çıkarın.
